# Лабораторная работа №1 — вариант 17

## Тема
«Интегрированная среда разработки ПО».

## Вариант 17
Программа «Идеальное похудение». Пользователь вводит возраст и пульс в состоянии покоя.
Программа рассчитывает тренировочный пульс по формуле Карвонена для зоны 60–70% резерва
пульса и выводит:
- пульс, с которого рекомендуется начинать кардиотренировки (60%);
- целевой пульс после адаптации (70%).

Реализован MVC с **активной моделью**: модель сообщает представлению об изменениях
через `PropertyChangeSupport`.

## Среда
- IntelliJ IDEA
- Java 17+
- Swing (GUI)
- Maven

## Структура
`src/main/java/by/bsuir/idealweight/`
- `Main.java` — точка входа;
- `model/WorkoutModel.java` — активная модель;
- `controller/WorkoutController.java` — контроллер;
- `view/MainFrame.java` — главная форма;
- `view/InputDialog.java` — отдельная форма ввода;
- `model/WorkoutData.java` — входные данные.

## Формула Карвонена
HRmax = 220 − возраст

HRR = HRmax − пульс_покоя

Целевой пульс = пульс_покоя + HRR × интенсивность

В проекте:
- стартовая интенсивность = 60%;
- целевая интенсивность = 70%.

Для учебной работы это расчёт по заданной формуле, а не медицинская рекомендация.

## Проверка
1. Запустить `Main`.
2. Нажать «Ввод данных».
3. Ввести возраст и пульс покоя.
4. Нажать «Рассчитать».
5. На главной форме появятся результаты.
6. При повторном открытии окна ввода последние значения автоматически восстанавливаются.
7. Некорректные значения вызывают сообщение об ошибке.

## Отладчик IntelliJ IDEA
Рекомендуемый пример для отчёта:
1. Открыть `WorkoutModel.calculate()`.
2. Поставить breakpoint на строке вычисления `heartRateReserve`.
3. Запустить Debug.
4. Ввести данные в форме.
5. Нажать «Рассчитать».
6. Проверить значения `maxHeartRate`, `heartRateReserve`, `startPulse`, `targetPulse`.
7. Использовать Step Over и окно Variables.

## Контрольные вопросы
1. Компоненты IDE: редактор, система сборки, компилятор/интерпретатор, отладчик,
   навигация и рефакторинг, система контроля версий, терминал, менеджер проектов и плагины.
2. Основные приёмы редактора: навигация по файлам и символам, автодополнение,
   поиск/замена, рефакторинг, форматирование, подсветка ошибок, переход к определениям.
3. Сборка и запуск: IDE/Maven компилирует исходники в `.class`, после чего JVM запускает
   главный класс `Main`.
4. MVC — Model, View, Controller: модель хранит и обрабатывает данные, представление
   отвечает за интерфейс, контроллер связывает действия пользователя с моделью.
5. Активная модель сама уведомляет заинтересованные представления/наблюдателей об
   изменениях состояния. Пассивная модель сама не инициирует уведомления, и контроллер
   обычно должен явно обновлять представление.
