## Описание проекта

Репозиторий создан как fork учебного репозитория
[BSUIR-SDLC/SDLC](https://github.com/BSUIR-SDLC/SDLC) и используется для выполнения
лабораторных работ по дисциплине. В нём последовательно выполняются все этапы
жизненного цикла программного продукта:

1. анализ и спецификация требований (SRS) — по шаблонам из папки `srs/`;
2. проектирование архитектуры (SDD) и фиксация архитектурных решений (ADR) — по шаблонам из папок `sdd/` и `adr/`;
3. разработка программного обеспечения — в папке `project/`;
4. тестирование, сборка и сопровождение.

Проект в папке `project/` — пустой шаблон Maven-проекта на Java 17, в котором
в дальнейшем будет выполняться проектирование и разработка задания.

## Структура репозитория

| Путь | Назначение |
|------|------------|
| `project/` | Maven-проект (Java 17), в котором ведётся разработка |
| `project/src/main/java/` | Исходный код |
| `project/src/main/resources/` | Ресурсы приложения |
| `project/src/test/java/` | Модульные тесты |
| `srs/`, `sdd/`, `adr/` | Шаблоны проектной документации (SRS, SDD, ADR) |
| `docs/` | Справочные материалы по стандартам и терминологии |
| `.gitignore` | Список временных файлов и папок, не попадающих в репозиторий |

## Ветки

| Ветка | Содержимое |
|-------|------------|
| `main` | Основная (стабильная) ветка |
| `lab1` | Материалы лабораторной работы №1 «Интегрированная среда разработки ПО» |
| `ProjectTemplate` | Шаблон проекта, README.md и .gitignore (слита в `main`) |

## Сборка и запуск

Требуется JDK 17+ и Maven 3.8+ (или IntelliJ IDEA со встроенным Maven).

```bash
cd project
mvn package
java -cp target/classes by.bsuir.sdlc.Main
```
